매주 자동 자리 순환

프로그램을 열거나 열린 화면으로 돌아오면 날짜를 확인합니다. 닫아 둔 동안의 지난 주차는 다음에 열 때 한꺼번에 반영합니다. 미확정 초안·고정 자리·조건 충돌이 있으면 배치를 유지하고 안내합니다.

백업 · 복원

백업은 학생 명단·사진·교실 구조·확정 이력을 담은 JSON 파일입니다. 프로그램에서 파일을 불러오면 그 상태로 복원할 수 있습니다.

브라우저 데이터 삭제나 기기 변경 전에 저장해 주세요. 백업에는 학생 정보가 들어 있으므로 개인 저장 공간에서 보관하세요.

백업 파일은 무엇인가요?

지금의 우리 반 설정을 한 파일에 담은 복원용 저장 파일(.json)입니다. PDF나 이미지와 달리 다시 불러와 편집할 수 있습니다.

  • 학생 번호·이름·사진과 배치 조건
  • 모둠·책상 모양, 순환 번호와 현재 자리
  • 확정한 배치 이력과 자동 순환 설정
저장 → 보관 → 복원
‘백업 파일 저장’을 누르고 개인 폴더에 보관하세요. 다른 기기에서는 프로그램을 열어 ‘파일로 복원’을 누르면 됩니다. 파일을 직접 수정할 필요는 없습니다.

저장 위치 선택 기능이 지원되지 않으면 브라우저의 다운로드 폴더로 내려받습니다. 브라우저가 다운로드를 막거나 저장을 취소했다면 파일이 실제로 생겼는지 확인해 주세요.

학생 사진과 이름이 포함되므로 단체 대화방이나 공개 게시판에 올리지 마세요. 실행 취소 기록은 현재 열려 있는 동안만 유지되고, 백업에는 현재 상태와 확정 배치 이력이 담깁니다.
