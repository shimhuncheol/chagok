# 차곡 · 선생님 할 일 정리

공문, 메신저, 메일 글을 **붙여넣기만 하면** 날짜별 할 일로 정리해 주는 선생님용 프로그램이에요.
설치나 로그인, 인공지능 API 없이 브라우저에서 바로 동작합니다.

👉 **바로 쓰기: https://shimhuncheol.github.io/chagok/**

## 이렇게 써요
1. **📥 자료 넣기**에서 공문·메신저 글을 복사(Ctrl+C)한 뒤 빈 칸을 한 번 누르면 바로 붙여넣어져요. 한글(.hwp·.hwpx)·워드(.docx)·텍스트 파일, **공문을 캡처한 이미지**(.png·.jpg)도 넣을 수 있어요.
2. 날짜별로 바로 정리돼요. 날짜·시간(24시간제)·내용을 고칠 수 있어요.
3. **✅ 입력**을 누르면 **📅 할 일 보기**에 오늘 · 이번 주 · 달력으로 쌓여요.

## 주요 기능
- 공문 날짜 표현 자동 인식: `2026. 11. 20.(금)`, `11월 20일`, `내일`, `다음 주 금요일`, `11. 30.~12. 4.` 등
- 🖼 그림 속 글자 읽기: 캡처한 공문 이미지에서 글자를 읽어 할 일로 정리(인터넷 없이, 이 파일 안에서 동작)
- 할 일·메모에 사진 붙이기, 자료함에서 원본 그림 보기 (사진도 백업 파일에 함께 들어가요)
- 휠 날짜 피커와 빠른 선택 칩, 반복 일정(매일·평일·매주·2주·매월)
- 오늘의 근무: 출퇴근 진행 바, 해·달 경로, 지역별 일출·일몰, 해 높이에 따른 화면 밝기
- 🏫 학교 정보(주소·우편번호·나이스 학교코드·연락처), 📝 메모
- 🪑 자리 배치: 학생 명부(사진 명부에서 사진·이름 추출, 엑셀 명단 붙여 넣기), 모둠·책상 모양 편집, 무작위 배치·자리 고정·맞교환, 매주 자동 순환, 배치 이력·같은 모둠 기록, 교사용·학생용 인쇄 — '우리 반 자리'를 차곡 안에 넣었어요. 디자인은 차곡 디자인을 따라가고, 자리 데이터도 차곡 백업 파일에 함께 들어가요
- 🏃 달리기 뽑기: 학생들이 달려서 결승선에 들어온 순서대로 뽑아요. 자리 배치의 사진 명부를 그대로 쓰고(사진 얼굴로 달려요), 명부가 없으면 이름만 적어도 돼요. **몇 명 뽑기**와 1인 1역 정할 때 좋은 **모두 순서 정하기**(전체 순서를 1번부터, 복사도 돼요)가 있어요. 선두가 바뀌거나 결승 직전에는 잠깐 느린 화면이 돼요. 이미 뽑힌 학생 빼기, 오늘 빠지는 학생 빼기, 크게 보기, 소리를 고를 수 있어요. 순위는 출발 전에 공정한 난수로 정해요
- 명령창(`Ctrl+K` / `⌘K` / `/`): 기능·할 일·메모·학교 정보 검색, 초성 검색
- 디자인: 오남초등학교(교표 색, 기본), K-에듀파인 스타일·나이스 스타일(글꼴까지 맞춤)과 7가지 스타일, **🏫 교표로 학교 디자인 만들기**(교표 그림을 넣으면 색을 뽑아 우리 학교 디자인으로)
- 화면 순서 바꾸기, 백업·불러오기

## 내 정보는 어디에 저장되나요?
할 일, 자료, 학교 정보, 메모, 자리 배치(학생 명단·사진)는 **각자의 브라우저 안에만** 저장되고 어디로도 보내지지 않아요.
이 저장소(GitHub)에는 프로그램만 있고, 선생님들의 내용은 올라오지 않습니다.

- 브라우저 기록(쿠키·사이트 데이터)을 지우면 내용도 지워질 수 있어요. **⚙️ 백업·정리 → 백업 파일 내보내기**를 가끔 해 두세요.
- 다른 컴퓨터·브라우저로 옮길 때는 백업 파일을 **불러오기** 하면 그대로 돌아와요.
- 예전에 `차곡.html` 파일로 쓰던 내용은 파일 버전에서 백업 → 이 주소에서 불러오기로 옮길 수 있어요.

## 앱으로 설치하기 (인터넷 없이도 열려요)
- **크롬·엣지(PC)**: 주소창 오른쪽의 설치 아이콘, 또는 차곡 왼쪽 메뉴의 **📲 앱으로 설치**
- **안드로이드**: 크롬 메뉴 → 홈 화면에 추가(앱 설치)
- **아이폰·아이패드**: 사파리 공유 버튼 → 홈 화면에 추가

한 번 열어 두면 인터넷이 끊겨도 열리고, 인터넷이 되면 자동으로 최신 버전으로 바뀌어요.

## 파일 하나로 쓰기
`index.html` 파일 하나만 내려받아 더블클릭해도 똑같이 동작해요(크롬·엣지 권장).

## 그림 속 글자 읽기
Tesseract.js 5.1.1 · Tesseract OCR · 한국어 학습 데이터(tessdata_best) — Apache License 2.0 (`NOTICE.txt`, `LICENSE-Apache-2.0.txt` 참고). 화면 캡처처럼 또렷한 글자는 잘 읽고, 종이를 찍은 사진은 틀리는 글자가 있을 수 있어요. 정리 결과의 **읽은 글자 고치기**로 바로잡을 수 있어요.

## 자리 배치
'우리 반 자리'(심훈철 제작)를 그대로 넣었어요. 예전에 '우리 반 자리' 사이트에서 저장한 백업 파일(`우리반자리_날짜.json`)은 **🪑 자리 배치 → 파일로 복원**으로 그대로 불러올 수 있어요.
사진 명부의 이름 읽기는 차곡의 한국어 글자 읽기 엔진을 써서 인터넷 없이 동작해요. 단, **PDF 명부**를 열 때는 PDF.js(Apache License 2.0)를 인터넷(cdnjs)에서 불러와요. JPG·PNG 명부는 인터넷 없이 돼요.
학생 사진과 이름이 들어 있으므로 백업 파일은 개인 저장 공간에 보관해 주세요.
